// Los genéricos en español: lo de todos los días, con un nombre neutro, el nombre de cada región y
// la porción más común. `npm run alimentos` los junta con USDA en assets/alimentos.db.
//
// Una línea por alimento:  español | inglés | de dónde sale | porciones | alias
// - De dónde sale: «sr:» (SR Legacy) o «fndds:» (FNDDS) y la descripción exacta de USDA; o, para lo
//   que USDA no tiene, «propio#N kcal proteína carbohidratos grasas» por 100 g (N no cambia nunca);
//   o, para un plato, «receta#N ingrediente gramos · ingrediente gramos → peso final»: los
//   ingredientes son curados de esta lista, y el peso final es lo que pesa terminado (cocinar
//   cambia el peso; sin él, la suma). Los valores por 100 g los calcula el armado.
// - Porciones: «1 mediana / 1 medium=118», separadas con « · ». La primera es la de siempre.
// - Alias: «palta* (AR UY)». Las regiones son códigos de país; con asterisco, es el nombre que se
//   muestra en esas regiones.
// «# categoría» abre una categoría.
